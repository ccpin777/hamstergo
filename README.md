# HamsterGo · 倉鼠打包小幫手 🐹

[English](README.en.md) ｜ 中文

一個純前端的行李打包檢查清單，設計成登機證（boarding pass）的樣式，就像有一隻小倉鼠陪你一起打包行李。可以安裝到手機主畫面，當作一般 App 使用。

## 功能

- **依天數自動計算數量**：襪子、上衣、內褲、隱形眼鏡（日拋，含備用）會依你設定的行程天數自動顯示需要帶幾份；衣物數量只顯示純數字，不另外寫出天數
- **打勾/打叉追蹤進度**：每一項目點一下是勾（帶）、點兩下是叉（這次不帶）、點三下清除；勾和叉都算進度，不再區分「必要品/非必需品」
- **證件流程**：預設國內線（駕照錢包），可切換國際線（護照）；按下「① 帶了」後，國際線／國內線切換鈕會自動隱藏，按「② 已收好」才算完成
- **手提行李／托運開關**：Carry-on 手提行李、Checked Baggage 托運行李各自有獨立開關；國內線預設「手提行李開、托運關」，國際線預設「兩者都開」，切換國內/國際線會自動套用對應預設值，之後仍可手動調整。只要托運開關是開的，衣物類（上衣、襪子、內褲、褲子、外套、鞋子、拖鞋）就會自動歸到 Checked Baggage；托運關掉時衣物則歸到 Carry-on
- **編輯模式**：編輯按鈕位於頁尾的「再次檢查」旁；進入編輯模式後，頁面最下方只有一個新增面板，可先選大類別，選擇 03 Carry-on 時再選小類別。已新增的項目可以改名或刪除。原始清單項目維持固定，不能刪改。衣物可在編輯時調整數量顯示方式；新增項目目前不再提供數量設定。新增的項目會存起來，就算按「開始新的旅程」重置勾選狀態，項目本身也不會消失
- **項目可拖曳排序**：編輯模式下，每個分類底下的項目右側會出現拖曳把手，按住上下拖曳即可調整同一分類內的順序（滑鼠與觸控皆可），順序會記住；分類本身順序固定，不能拖動，也不能跨分類拖曳
- **出發前提醒**：新增第 05 區塊 `Pre-departure reminders 出發前提醒`，作為提醒清單；項目保留勾選狀態，但不計入主行李完成率
- **狀態提示**：頂部會依完成度切換成「🐹 今天要出發了！還有 n 項沒帶。」或「🐹 行李整理完成！ ✈️」；主完成率只計 01 到 04，不含 05
- **再次檢查**：可一鍵清掉所有已打勾項目，保留原本打叉的項目，方便同一份清單重新檢查
- **通關提醒**：出發前 / 安檢後兩個時間點的證件提醒
- **本機儲存**：勾選狀態、天數設定、自訂項目都存在瀏覽器的 `localStorage`，只留在你自己的裝置上，不會上傳到任何伺服器
- **可安裝成 PWA**：加到手機主畫面後可全螢幕開啟；有網路時優先取得最新頁面，離線時使用快取內容
- **字體大小設定**：右上角齒輪可切換小、標準、大、特大文字，設定會保存在本機
- **旅行紀錄匯出／匯入**：可在登機證上方命名此次旅行；匯出 JSON 會使用旅行名稱作為檔名，也可從齒輪設定匯入紀錄
- **直接設定行程天數**：旅行名稱旁可直接輸入 1–30 天，數量會隨之更新；輸入欄不顯示上下箭頭

## 檔案結構

```
.
├── index.html          # 主要頁面與邏輯
├── manifest.json        # PWA 設定（名稱、圖示、顏色、啟動模式）
├── service-worker.js    # 離線快取邏輯
├── resource/
│   ├── icon-192.png         # App 圖示（192×192）
│   ├── icon-512.png         # App 圖示（512×512）
├── deploy.command       # 雙擊即可 commit + push 到 GitHub 的部署腳本
└── dev-log.md           # 開發紀錄
```

## 本機測試

因為 Service Worker 需要 HTTPS 或 localhost 才能註冊，不能直接雙擊 `index.html` 用 `file://` 打開測試。用任何簡易的本機伺服器起一個就好，例如：

```bash
python3 -m http.server 8000
```

然後瀏覽器打開 `http://localhost:8000`。

## 部署到 GitHub Pages

第一次設定：

1. 建立一個新的 GitHub repository（Public）
2. 在這個資料夾執行 `git init`，並加上這個 repo 的 remote（`git remote add origin <repo網址>`）
3. 把這幾個檔案 commit 並 push 上去（放在 repo 根目錄，不要包在子資料夾裡）
4. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main** / **root**，儲存
5. 等 1–2 分鐘後，會拿到一個網址：`https://你的帳號.github.io/repo名稱/`
6. 手機瀏覽器打開這個網址 → 加到主畫面，即可像 App 一樣全螢幕使用

之後每次修改完，雙擊 `deploy.command`，輸入這次改了什麼、要不要打版號，就會自動 commit + push。

## 資料儲存說明

所有資料都存在**這支手機、這個瀏覽器**裡（`localStorage`），不會同步到其他裝置，也不會有任何人（包含開發者）看到你的資料。清除瀏覽器資料或換手機都會讓資料重置。

## 客製化

- 想調整清單項目、分類，直接編輯 `index.html` 裡的 `getData()` 這個函式
- 想換配色，改 `index.html` 最上面 `:root` 裡的 CSS 變數（`--navy`、`--amber` 等）
- 想換圖示，重新產生 `resource/icon-192.png` / `resource/icon-512.png` 並保持相同檔名即可
